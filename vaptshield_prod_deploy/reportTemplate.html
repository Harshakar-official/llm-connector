A Appendix A — Severity Ratings

Vulnerability metric metrics conform to specifications governed under the CVSS v4.0 framework standardization models.

Severity Index CVSS Bounds Engineering Hazard Architectural Definition Guidelines Color
Critical 9.0 – 10.0 Flaws exposing zero dependency access vectors. Exploitation yields unauthenticated root level data orchestration control and system takeovers.
High 7.0 – 8.9 Vulnerabilities enabling privilege access manipulation patterns, mass database scraping, or core pipeline data loss triggers.
Medium 4.0 – 6.9 Exploitation signatures involve restricted configurations, local boundary authorization contexts, or active target user social manipulation hooks.
Low 0.1 – 3.9 Configuration exposure issues that trigger minor platform service footprints without exposing system manipulation endpoints.
